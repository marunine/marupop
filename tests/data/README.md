# Test data

`dict/MockJMdict.xml` comes from JL's `JL.Core.Tests/Resources/MockJMdict.xml`.
JL is Apache-2.0; the embedded JMdict material retains the copyright of James William BREEN
and the Electronic Dictionary Research and Development Group and its CC BY-SA 4.0 terms.
See [NOTICE](../../NOTICE), [the license text](../../LICENSES/CC-BY-SA-4.0.txt) and
[EDRDG's licensing statement](https://www.edrdg.org/edrdg/licence.html). Do not relabel the
dictionary extract as MaruPop-owned data.

The other small dictionary and lookup files are hand-written parser fixtures under the
project's LGPL-3.0-only license. Their names, readings, revisions and dates are deliberate test
inputs, not records of a user's dictionary installation. The two `.png` files under
`dict/yomitan_v3/img/` contain only the eight-byte PNG signature: they test archive resource
paths and contain no image content or metadata.

`ocr/meikicorrections_cases.json` contains synthetic cases generated by the standalone Python
reference described in [the generator documentation](../../tools/README.md). It is not an
export of captured screen text or an external evaluation corpus. Expected results from that
reference exercise the separate C++ correction implementation.

The fixture paths and notices belong in source archives. Test data is not installed with the
application; the top-level license and component notices are installed for binary recipients.
